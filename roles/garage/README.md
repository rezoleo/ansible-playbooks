# Garage

## About Garage

Garage is an S3 provider developed by [deuxfleurs](https://garagehq.deuxfleurs.fr/), designed to be lightweight and higly resilient.

Nextcloud is a [supported client](https://garagehq.deuxfleurs.fr/documentation/connect/apps/#nextcloud).

## About the role

This role instals Garage, create the buckets, manage the keys using the API. It also handles minors update (tested from 2.5 to 2.6).
